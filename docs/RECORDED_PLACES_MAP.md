# 記録地点から探す地図

`/map` は既存の日本地図 SVG を使い、都道府県から資料記載地点、個別記録へ進む閲覧画面です。外部タイル、座標、位置情報 API は利用しません。SVG の出典表示は画面内に置きます。

`src/recordedPlaces.ts` が公開中の `repository.dialects()` から毎ビルド時に閲覧用の集約を作ります。`source` または `additionalSources` に有効な資料 URL・資料名・確認日と `region` の証拠範囲を持つレコードだけを地図に含めます。`municipality` があればその文字列を、なければ `locality` を資料記載地点として使い、どちらもなければ「県内の地点未特定」に分けます。`evidenceRegion` の説明文から市町村名を抽出しません。旧地名も変換しません。県内件数は同じ ID を重複して数えません。

表示する地名は既存レコードの地理 claim です。資料の原文との claim 単位の再照合は県別データ整備の担当範囲です。地図の選択は都道府県の絞り込みであり、その県や地名の全域での使用、あるいは特定座標での発話を主張しません。出典未確認で地域の証拠範囲がない候補は地点に配置しません。確認作業中で地域資料だけ確認できている記録は状態を明示して含みます。

都道府県の SVG 操作と同じ情報への一覧 UI を併設します。初期描画時には 47 都道府県の集約だけを示し、記録カードは地点選択後に作ります。既存 SVG は約 147 KB、追加の `/map` JavaScript chunk は gzip 約 2.8 KB です。既存の方言カタログはアプリ全体の共通依存であり、今後そこを遅延読込化する余地があります。

地図の状態は `?prefecture=` と `&place=` で共有できますが、検索対象となるページは `/map` のみです。クエリ付きアクセスにも同一 canonical を設定し、静的 sitemap に状態別 URL を追加しません。県別 authoritative JSON、共通 `regions.json`、方言の ID や URL は変更しません。
